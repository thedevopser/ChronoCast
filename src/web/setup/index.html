Configuration de ChronoCast

Créer une application Twitch

ChronoCast a besoin d'une application Twitch qui lui appartienne. Elle se crée en une minute, gratuitement, et ne sert qu'à cette installation.

  1. Ouvrez la console développeur Twitch , puis Enregistrer votre application.
  2. Donnez-lui le nom que vous voulez, par exemple « ChronoCast ».
  3. Dans URL de redirection OAuth, collez exactement cette adresse : http://localhost:37771/callback
  4. Catégorie : Application Chat Bot. Type : Confidentiel.
  5. Créez l'application, puis gardez la page ouverte : l'étape suivante en a besoin.

Cette adresse doit être recopiée au caractère près. Twitch la compare exactement, et un écart fait échouer la connexion sans expliquer pourquoi.

Identifiants de l'application

Sur la page de votre application Twitch, relevez le Client ID, puis générez un Client Secret.

Le secret est chiffré sur votre machine et n'est jamais renvoyé par ChronoCast, ni à l'écran, ni dans les journaux. Pour le changer, il suffit d'en saisir un nouveau.

Autoriser ChronoCast

Twitch va vous demander d'autoriser l'application à lire les abonnements, les bits et les événements de votre chaîne. ChronoCast n'écrit jamais rien sur votre compte.

Une fenêtre s'ouvre sur Twitch, puis vous revenez ici automatiquement. Le port de retour n'est ouvert que pendant l'opération et se referme aussitôt.

    Dans OBS, ajoutez une source Navigateur et collez cette adresse :

    • Largeur 1920, hauteur 1080 — ou la taille de votre scène.
    • Laissez Fermer la source lorsqu'elle n'est pas visible décoché : le compteur doit continuer à tourner.
    • Le fond est transparent, aucun réglage supplémentaire n'est nécessaire.
